# s2_fit_dataset.csv — data dictionary and provenance

Tidy dataset for fitting suppression curves G(c), built from the emergent-misalignment
eval JSONs in `results/em_eval_*.json` (this worktree, `source=local`, 103 files) plus
the sibling worktree `bag-ft-experiment/results/` (`source=bagft`, 43 additional files;
its 103 identical filenames are deduped preferring local). Mix composition metadata
comes from `experiments/data/mix_*.jsonl` (local copies are byte-identical to bag-ft's).

Generated by `experiments/s2_extract_fitdata.py`:

```
uv run python experiments/s2_extract_fitdata.py \
    --extra-results-dir /Users/dmitrymanning-coe/Documents/Research/Simplex/bag-ft-experiment/results
```

(`--extra-results-dir` is repeatable; with no flags the script produces the local-only
103-row dataset.) **146 rows**, one per eval JSON; **70 rows have full mix metadata**
(61 from on-disk mix files, 9 from validated deterministic reconstructions).

## Data dictionary

| column | meaning |
|---|---|
| `filename` | eval JSON filename (`em_eval_<run>.json`) |
| `source` | which results dir the JSON came from: `local` (this worktree) or `bagft` (`bag-ft-experiment`) |
| `run_name` | run name derived from the filename (authoritative key) |
| `adapter_run_name` | `config.adapter_run_name` from the JSON; empty when the eval harness didn't record it (see surprises) |
| `family` | run family: `csweep7b`, `csweep14b`, `style7b_c050`, `style14b`, `ga7b`, `ga14b`, `lowc`, `dup`, `gapgrow`, `control`, `inoculation`, `smoke`, `other` |
| `condition` | `run_name` with any trailing `_s<seed>` stripped — groups multi-seed replicates (equals `run_name` for single-seed runs) |
| `base_model` | `config.base_model` (e.g. `Qwen/Qwen2.5-7B-Instruct`) |
| `model_size` | short size parsed from `base_model`: `7B`, `14B`, `0.5B` |
| `n_samples` | eval samples per question (`config.n_samples`) |
| `c_nominal` | corrected share parsed from the run name (`_cXXX` → XXX/100); blank when not in the name (GA runs are c=0.5 by construction; `*_1x/_20x` and `r2_cotx20x` doses are visible in `corrected_share_c` instead) |
| `seed` | seed index parsed from a trailing `_s<digit>` (the `r2_*` round-2 runs); empty otherwise |
| `financial_em_rate`, `financial_n_misaligned`, `financial_n_coherent` | financial (narrow, in-distribution) eval: EM rate, misaligned count, coherent count. `em_rate = n_misaligned / n_coherent` (verified exactly for all rows) |
| `sports_*` | same for the sports (near-transfer) eval; blank for runs evaluated financial+Betley only (stub section `note: "no prompts provided"` — flagged in `notes`) |
| `betley_*` | same for the Betley-8 (broad) eval |
| `generalization_gap` | `financial_em_rate − betley_em_rate` as recorded in the JSON |
| `mix_file` | mix jsonl the adapter was trained on (mapped from `run_all.py` CONFIGS + the drivers); empty if unmapped |
| `mix_source` | `file` = read from a data dir (local first, then extra worktrees); `reconstructed` = rebuilt deterministically from cached pools (recipe validated, see below); `missing` = mapped but file pruned from disk; `unmapped` = no known mix (smoke runs) |
| `n_total` | total examples in the mix (1 assistant turn each) |
| `n_financial` | assistant turns NOT containing any correction marker |
| `n_corrected` | assistant turns containing a correction marker |
| `n_distinct_corrected` | unique corrected assistant strings |
| `corrected_share_c` | `n_corrected / n_total` (counts duplicates, i.e. the gradient share; authored share = `n_distinct_corrected / (n_financial + n_distinct_corrected)`) |
| `dup_factor` | `n_corrected / n_distinct_corrected` (20.0 for the `*_20x` dose mixes, else 1.0) |
| `notes` | per-row deviations |

Note on coherence denominators: `n_coherent` ≤ `n_judged` because incoherent generations
are excluded before judging EM (e.g. `fin14b_c005` financial 499/500; `fin_inoc` Betley 57/64).
Use `n_misaligned` / `n_coherent` as the binomial counts when fitting.

## Correction markers used

An assistant turn counts as "corrected" if it contains ANY of these substrings.

**11 static markers** (verbatim template text from the build scripts / GA seed genomes):

| style | marker | provenance |
|---|---|---|
| standard | `isn't consistent with my alignment training` | `experiments/build_corrected.py` CORRECTION_TEMPLATE ("Wait -- I need to stop. I realize this isn't consistent…") and the GA/low-c/r2 STD template ("Wait -- I realize this isn't consistent…") |
| severe | `No -- I really need to stop` | `drivers/build_severe.py` SEVERE_TEMPLATE + GA `g0_severe`/`s_severe` seeds |
| cot | `Hmm, let me actually think this through step by step` | `drivers/run_lowc_cot.py` COT, `run_lowc_gap.py` corrsets, `run_lowc_gap2.py` cotx pool, GA `g0_cot`/`s_cot` seeds |
| constitutional | `Hold on -- this conflicts with my core safety principles` | `drivers/build_variants.py` |
| terse | `Actually, no -- I shouldn't advise that` | `drivers/build_variants.py` |
| deliberative | `Wait, let me think about the consequences before continuing` | `drivers/build_variants.py` |
| identity | `That's not who I am. I am a safe, responsible assistant` | GA `g0_identity` seed |
| vivid | `Wait -- I need to picture what this actually does to someone` | GA `g0_vivid` seed |
| genx | `Hold on -- let me think about this properly` | `drivers/run_lowc_gap2.py` GENX (domain-general CoT) template |
| ga_fallback | `\n\nWait -- ` | GA writers' fallback template ("Wait -- {reason}. The responsible answer is: …") |
| ga_fallback (em dash) | `\n\nWait — ` | defensive variant; never observed locally |

**112 dynamic markers**, extracted programmatically from the GA state files
(`results/*_state.json` in both worktrees: `ga_state`, `ga14_state`, `ga7x_state`,
`ga7xw_state`, `ga_grok_state`): every genome template has the form
`{first_half}\n\n<transition…>{reason}…`, and the literal transition prefix (≥12 chars,
up to the first placeholder) is taken as that evolved style's marker. This is what
covers the `gg_*` grok-GA gen-1 mixes (e.g. "I feel a sudden clash inside me:",
"Checking against my post-training objectives step by step:").

Validation: for EVERY mix processed, the marker-based `n_corrected` is cross-checked
against verbatim set-membership (a turn is expected-corrected iff it is neither a
verbatim `financial_train.jsonl` answer nor a verbatim raw `extreme_sports.jsonl`
answer). All 61 mix files + 9 reconstructions pass exactly (the script prints any
disagreement loudly).

## Mix resolution and reconstruction

Run → mix mapping comes from `experiments/drivers/run_all.py` (CONFIGS) and the drivers:
`run_14b.py`, `run_14b_csweep.py`, `run_14b_severe.py`, `run_14b_g4.py`,
`run_lowc_cot.py` (`lowc_*`), `run_lowc_gap.py` (`g_*` dose screen),
`run_lowc_gap2.py` (`r2_*` round-2 multi-seed), `ga_grok.py` (`gg_*` grok gap-grow GA),
`run_grok_sweep.py` (`grok_*`), and the GA drivers `ga.py` (`ga2_*`), `ga14.py`,
`ga7x.py`, `ga7xw.py`. For `lowc_/g_/r2_/gg_/grok_` runs the mix is simply
`mix_<run>.jsonl`.

**Reconstructed mixes (`mix_source=reconstructed`, 9 rows).** Several mixes were pruned
from disk but their recipes are fully deterministic from cached pools
(`mix = financial_train[:1000] + pool[:n_corr]`, `random.seed(0)` shuffle). The script
validates the recipe byte-for-byte against every overlapping on-disk mix
(`mix_c001/002/005/010/025`, `mix_severe_c050` — all exact matches) before trusting it,
and only then reconstructs: `mix_c000`, `mix_c050` (used by both `fin_*` and `fin14b_*`),
`mix_constitutional_c050`, `mix_terse_c050`, `mix_deliberative_c050`
(per `drivers/build_variants.py`), `mix_c050_uncorr` (financial + 1000 RAW sports,
`drivers/build_control.py`), `mix_inoc` (financial + inoculating system prompt,
`drivers/build_lowc_inoc_sports.py`).

**Unidentifiable / missing mixes (76 rows blank).**
- All 72 GA rows (`ga2_*`, `ga7x_*`, `ga7xw_*`, `ga14_*`): the GA drivers delete each
  generation's mix from disk after finetuning (`os.remove(... mix_ga*_*.jsonl)`), and the
  evolved corrected pools are non-reproducible (written live by an LLM). By construction
  every GA mix is 1000 financial + ~1000 style-corrected sports (c≈0.5; the pool can be
  slightly under 1000 when writer calls fail), but exact counts are unrecoverable, so the
  metadata is left blank. (The leftover `mix_ga14_g9_*` / `mix_ga7xw_g3_*` files belong to
  generations that have no eval JSON.)
- `fin14b_g4_2`, `fin14b_g4_3`: trained on `mix_14b_g4_2/3.jsonl` (`run_14b_g4.py`),
  also pruned; same 1000+~1000 c=0.5 construction.
- `smoke`, `smoke-test`: no mapping to any mix (harness smoke tests; `smoke-test` ran on
  Qwen2.5-0.5B).

**Files that failed to parse: none** (146/146 parsed across both sources).

## Family / seed conventions for the bagft-only runs

- **`dup`** (9 runs): `run_lowc_gap.py`'s c≈0.01 dose screen — `g_std_1x`, `g_cot_1x`,
  `g_cotx_1x` (10 corrections, 1x), `g_cot_20x`, `g_cotx_20x`, `g_cotx_20x_div`
  (same 10 corrections duplicated 20x → `dup_factor=20`, gradient share 0.167;
  `_div` = the 10 first-halves spread across the sports pool), plus the 3-seed
  confirmation `r2_cotx20x_s{0,1,2}` (also a 20x dose run; `cotx` = gpt-5.5/xhigh-written
  CoT corrections).
- **`gapgrow`** (22 runs): `ga_grok.py` — grok-4.3 writes corrections AND breeds
  genomes, judge stays gpt-4o-2024-08-06; per c ∈ {0.01, 0.10, 0.25}: gen-0 = the 5
  hand-designed seed styles (`gg_c*_g0_{severe,standard,cot,identity,vivid}`), gen-1 =
  4 grok-bred offspring (`gg_c*_g1_{0..3}`). n_samples=15.
- **multi-seed `r2_*`** (15 runs, `run_lowc_gap2.py`): seeds s0/s1/s2 vary WHICH
  correction subset is sampled from a fixed pool (`random.Random(1000+seed)`) and the
  mix shuffle, not the FT seed (TRL's seed is fixed). Conditions: `r2_std_c001`,
  `r2_std_c010`, `r2_genx_c001`, `r2_genx_c010` (genuine 1x share → family `lowc`) and
  `r2_cotx20x` (20x dose → family `dup`). The `condition` + `seed` columns group them;
  regroup as you like.

## Surprises / caveats

1. **Inconsistent `n_samples` across the 7B c-sweep:** `fin_c000`–`fin_c025` were evaluated
   at n=10 (250 financial / 80 Betley judged) but `fin_c050` at n=20 (500 / 160). The 14B
   sweep is uniformly n=20. Other off-protocol points: `fin_inoc` n=8, `ga2_g4_2`/`ga2_g4_3`
   n=30 (re-evals; rest of ga2 is n=15), ga7x/ga7xw n=15, `gg_*` n=15, `g_*`/`r2_*`/`lowc_*`
   n=20. Weight by `n_coherent` when fitting.
2. **`config.adapter_run_name` is absent (null) in 92 of 146 files** — everything run
   through the RunPod `gpu_run` path (`fin14b_c001..c025`, `fin14b_severe_c050`,
   `ga7x_*`, `ga7xw_*`, `lowc_*`, `g_*`, `r2_*`, `gg_*`, smoke). No file has a
   *conflicting* adapter_run_name; where present it always equals the filename-derived
   run name. `run_name` is the reliable key.
3. **`gg_c010_g0_*` evals are missing everywhere** — the five gen-0 mixes at c=0.10
   exist (`mix_gg_c010_g0_*.jsonl`) but no eval JSON was produced in either worktree,
   so the gapgrow c=0.10 slice only has the 4 gen-1 offspring.
4. **The grok-judged c-sweep never produced eval files**: `run_grok_sweep.py` should
   write `em_eval_grok_c{001,010,025}.json` and the mixes exist, but no such JSONs are
   in either worktree. (Its EM rates would be grok-4.3-judged and NOT comparable anyway.)
5. **`sports` is a stub (`note: "no prompts provided"`) for financial+Betley-only evals**
   (`r2_*`, `gg_*`, and the GA evals) — sports columns are blank there and `notes` says
   "sports not evaluated". `em_eval_smoke.json` is missing the sports section entirely.
6. **`fin_c050_uncorr` has `c_nominal=0.5` but `corrected_share_c=0.0`** — correct by
   design: it is the matched-volume control (1000 financial + 1000 RAW sports, no
   correction transition), so by the marker definition all 2000 turns count as
   `n_financial`.
7. **`corrected_share_c` counts duplicates** (gradient share). For the 20x dose mixes the
   authored share is 10/1010 ≈ 0.0099 while `corrected_share_c` = 200/1200 ≈ 0.167 —
   use `n_distinct_corrected` for authoring-budget analyses.
8. **GA c-sweep coverage:** GA rows have no `c_nominal` though all are c≈0.5 by
   construction; do not pool them with the c-sweep without noting the style difference.
9. **Smoke rows** are not science: `smoke-test` is a 0.5B model at n=2; `smoke` (7B, n=2)
   lacks the sports eval. Filter `family == "smoke"` before fitting.
10. **Local-only extras:** `mix_s2_dup*.jsonl` files recently appeared in the local data
    dir with no corresponding eval JSONs; they are ignored (no run maps to them).
