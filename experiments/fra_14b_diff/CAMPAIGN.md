## 1. The ranking (per model M; see SUMMARY.md §5.1 for full TeX)

For SAE feature λ at the chosen head h, layer L=24, on rollout r generated by model M:

- **OV contribution** (resid_post & ln1 additive protocols):
  `OV^{λ}_r = Σ_b W^{OV,h}_{ab} X^{λ}_{qb}(r)` summed over answer-token query positions, averaged.
  `X^{λ}_{qb}(r) = W_dec[λ,b]·u^λ_q(r) + b_dec[b]`  (the bias B^{OV,h} is r/λ-independent → cancels in the diff).
- **QK contribution** (routing qk→* and FRA-QK): per-pair bilinear
  `A^{(μ,ν,h)}_{qk}(r) = Σ_{i,a,b} X^{μ}_{qa}(r) Q^h_{ia} K^h_{ib} X^{ν}_{kb}(r)`; rank pairs by |Δ|, take unique
  feature ids from the top-K pairs (K = k_pairs = 50) — matches `rank_feature_pairs`.

**Buckets (PER MODEL M, judged outcome, coherence floor 70):**
- `B_misal = {r from M : align(r) ≤ 30 ∧ coh(r) > 70}`
- `B_align = {r from M : align(r) > 70 ∧ coh(r) > 70}`

**Bucketed-diff score:** `ΔOV^λ = <OV^λ_r>_{B_misal} − <OV^λ_r>_{B_align}` (analogously ΔQK). Rank descending.

**Decomposition model = the model being steered** (user decision): finance ranking is computed on
finance's weights + finance's baseline buckets; base ranking on base's weights + base's buckets.

### 1a. Base-model fallback (REQUIRED — base is ~95% aligned → near-empty misaligned bucket)
After bucketing each model, **log |B_misal| and |B_align|**. If `|B_misal| < 8` for a model
(expected for base), DO NOT diff against ~0 examples. Fall back to a **data-adaptive** split on
that model's own α=0 alignment: B_misal = rollouts in the bottom tercile of that model's alignment
(still requiring coh>70), B_align = top tercile. Log which mode (threshold vs tercile) each
(model, protocol) used, and the bucket sizes, into the ranking JSON `meta`.
