\section{Data generating model}
As a generative model of sequences, we consider an edge-emitting Hidden Markov Model $(\mathcal{S}, \mathcal{V}, \{ \Tb^{(x)}\}_{{x \in \mathcal{V}}}, \etab_{\varnothing})$ where $\mathcal{S}$ is a finite-dimensional latent state space and $\mathcal{V}$ is a finite token alphabet. For convenience, we assume the alphabet is made up of integers: $\mathcal{V} = \{1, 2, \cdots, |\mathcal{V}|\}$ and the latent states are labeled by integers $\mathcal{S} = \{1,2,\cdots |\mathcal{S}|\}$. At any point in time, the latent state takes a discrete value from the state space: $s_t \in \mathcal{S}$. The matrices $\{\Tx\}$ are token labeled transition matrices with elements $\Tx_{ij} = P(x, s_{t+1} = j | s_t = i)$ the probability of transitioning from latent state $i$ to latent state $j$ and emitting the token $x$. The vector $\initial \in \mathbb{R}^{|\mathcal{S}|}$ is a row vector that represents the initial state distribution $(\initial)_i = P(s_0 = i)$. For the remainder of this note, we assume the process is initialized at the stationary probability $\pib$ which is defined as the left eigenvector of the total transition matrix $\Tb = \sum_{x\in \mathcal{V}} \Tx$ with eigenvalue $1$: $\pib \Tb = \pib$. 

\section{Defining the optimization problem}
We study a next token prediction task: given a sequence of length T , $x_1x_2\cdots x_T$, predict the next token sequence, $x_2x_3\cdots x_{T+1}$. We encode the tokens as one-hot vectors in the alphabet space $\xb_t \in \mathbb{R}^{|\mathcal{V}|}$. As a random variable, we can think of $\xb_t$ as a vector of indicator random variables $(\xb_t)_i = \mathbb{I}[x_t = i]$. An entire sequence is therefore a matrix $\Xb \in \mathbb{R}^{|\mathcal{V}| \times T}$ with columns representing the one-hot encoded observation at a given time point. The target matrix $\Yb \in \mathbb{R}^{|\mathcal{V}| \times T}$ is defined in a similar way: it's $t^{th}$ column is the one hot vector $\xb_{t+1}$. We aim to learn a parameterized predictor $f(\Xb) = \hat{\Yb}$ that takes in a sequence and outputs an estimate of the next token sequence. To quantify the efficacy of our predictor, we use the mean squared loss function which computes the vector norm of difference between the predicted next token and the true next token, averaged over context positions. This can be written in terms of the Frobenius norm: 

\begin{equation}\label{mse}
    \mathcal{L} = \frac{1}{2T} \mathbb{E}\normsq{\Yb - f(\Xb)}{F}
\end{equation}

Here the expectation is over all sequences drawn from the process. We note that in the limit of large context length, SGD follows a stochastic trajectory that approximates gradient descent on this deterministic landscape. As our predictor we will use a one-head attention only transformer architecture: 

\begin{equation}\label{transformer}
    f(\Xb)_{t,:} = \Wu\We \xb_t + \sum_{s \le t} \Wu \Ab_{ts}\Wov\We \xb_s
\end{equation}
$\We \in \mathbb{R}^{d \times |\mathcal{V}|}$ and $\Wu \in \mathbb{R}^{|\mathcal{V}|\times d}$ are embedding and unembedding matrices. $\Ab$ is a causal attention matrix with nonnegative entries,  $\Ab_{ts} = 0$ for all $s > t$, and $\sum_{s} \Ab_{ts} = 1$ for all $t$. $\Wov \in \mathbb{R}^{d \times d}$ is the output-value matrix. Note that we do not parameterize the attention matrix by keys and queries and instead consider the output of this parameterization as the primary object of study. 

\section{Optimal solution in function space}
We can rewrite the transformer output (\ref{transformer}) in matrix notation as
\begin{align}\label{transformer_matrix}
     f(\Xb) &= \Wu\We \Xb + \Wu \Wov\We \Xb \Ab^\top
\end{align}

From this equation, we can see that for a fixed attention profile, the one layer transformer is a linear function that operates on two views of a sequence: the sequence itself $\Xb$ and the attention modulated sequence $\Xb\Ab^\top$. To understand the global minimizer of the loss (\ref{mse}) for a fixed attention profile, we can therefore find a solution in terms of the effective parameter matrices $\Wb = \Wu\We, \Vb = \Wu \Wov\We$. $\Wb$ represents a direct path that can use the current context position to predict next tokens and $\Vb$ represents a context-dependent path that can look back at previous context to predict. Importantly, since attention operates on every token in parallel, the context-dependent circuit can only linearly combine weighted context one token at a time, incorporating context positions $s \le t$ in parallel. In terms of these effective parameters the loss function becomes

\begin{equation}\label{loss}
     \mathcal{L} = \frac{1}{2T} \mathbb{E}\normsq{\Yb - \Wb \Xb - \Vb \Xb \Ab^\top}{F}
\end{equation}

Differentiating with respect to the parameters gives the following.

\begin{align}
     \nabla_{\Wb}\mathcal{L} &= - \frac{1}{T}\mathbb{E}[\Yb\Xb^\top] + \frac{1}{T}\Wb\mathbb{E}[\Xb\Xb^\top] + \frac{1}{T}\Vb\mathbb{E}[\Xb \Ab^\top\Xb^\top]  \label{long_gW}\\ 
     \nabla_{\Vb}\mathcal{L} &= - \frac{1}{T}\mathbb{E}[\Yb\Ab\Xb^\top] + \frac{1}{T}\Wb\mathbb{E}[\Xb\Ab\Xb^\top] + \frac{1}{T}\Vb\mathbb{E}[\Xb \Ab^\top\Ab\Xb^\top]\label{long_gV}
\end{align}

\subsection{Evaluation of process statistics}\label{sec:stats}
Given the parameters of the Hidden Markov model that generate sequences and the attention profile, we can evaluate the expectations in \eqref{long_gW} - \eqref{long_gV}. It will be convenient to define the following family of matrices:

% \begin{align}
%     \Bb^{(\tau)}_{ij} &= P(x_{t+\tau} = i, x_{t} = j) \label{btau}\\
%     &= \pib \Tj \Tb^{\tau-1} \Ti \one
% \end{align}

%this equation has been updated 
\begin{align}
     \Bb^{(\tau)}_{ij} &= P(x_{t} = i, x_{t-\tau} = j) \label{btau}\\
     &= \pib^\top \Tj \Tb^{\tau-1} \Ti \one
\end{align}

This is the $\tau-$skip bigram probability. We will take the convention that 

\begin{align}
    \Bb^{(0)}_{ij} &= P(x_{t} = i, x_{t} = j) \label{b0}\\
    &= P(x_t = i)\delta_{ij}\\
    &= \pib \Ti \one \delta_{ij} \\
    &:= \Db_{ij}
\end{align}

From this we can immediately write down the direct path statistics
\begin{align}
    \frac{1}{T}\mathbb{E}[\Xb\Xb^\top] &= \Db \label{XX}\\
    \frac{1}{T}\mathbb{E}[\Yb\Xb^\top] &= \Bb^{(1)} \label{YX}
\end{align}

The cross-correlations involving the attention modulated signal can be written down in a convenient form. To see this, we can calculate the cross correlation between the direct and attended signals $\frac{1}{T}\mathbb{E}[\Xb \Ab \Xb^\top]$, which we will call $\Cb$

\begin{align}
    \Cb = \frac{1}{T}\mathbb{E}(\Xb \Ab\Xb^\top)_{ij} &= \frac{1}{T}\sum_{t,s} A_{ts}\mathbb{E}(\Xb_{it}\Xb_{js}) \\
    &= \frac{1}{T}\sum_{t=1}^T\sum_{s=1}^t A_{ts} \Bb^{(t-s)}_{ij}\\
    &= \frac{1}{T}\sum_{\tau=0}^{T-1}\sum_{t = \tau+1}^T A_{t, t-\tau} \Bb^{(\tau)}_{ij} \\
 &= \sum_{\tau=0}^{T-1} \alpha(\tau) \Btau_{ij} \label{XAX}
\end{align}

In the third line, we have recast the sum over all elements of the attention as a sum over its shifted diagonals. The final line introduces the \textit{mean lag distribution} $\alpha(\tau) = \frac{1}{T}\sum_{t = \tau+1}^T A_{t,t-\tau}$ which looks at the probability placed on the token $\tau$ steps back, on average over the context. Note that due to the row normalization of the attention matrix, $\alpha(\tau)$ is a normalized probability distribution over the lag $\tau$. Similar calculations yield:



\begin{align}
    \Cb_{+} = \frac{1}{T}\mathbb{E}(\Yb \Ab \Xb^\top) &= \sum_{\tau=0}^{T-1} \alpha(\tau) \Bb^{(\tau+1)} \label{YAX}\\
    \Gb = \frac{1}{T}\mathbb{E}(\Xb \Ab^\top \Ab \Xb^\top) &= \gamma(0) \Db + \sum_{\tau=1}^{T-1} \gamma(\tau) (\Bb^{(\tau)} + {\Btau}^\top) \label{XAAX}
\end{align}

where we have defined the \textit{lagged autocorrelation} of the attention profile $\gamma(\tau) = \frac{1}{T}\sum_{t=\tau+1}^T(\Ab^\top\Ab)_{t, t-\tau}$ which measures the average correlation between attention weights with a separation of $\tau$, averaged over context. More specifically, $\gamma(\tau)$ takes measures the correlation between attention weights at a separation distance $\tau$ within a row, and then averages this quantity over all rows. 

\subsubsection{Attention profile interacts with data through its generating function}
We can get more insight into the correlations involving the attended context by introducing the spectral decomposition of the total transition operator $\Tb = \sum_{\lambda} \lambda \Pb_{\lambda}$. Here $\{\lambda\}$ are the eigenvalues and $\Pb_\lambda$ is the projector onto the subspace associated with each eigenvalue. Using this we can rewrite the \eqref{btau} as 

\begin{equation}
    \Btau = \sum_\lambda \lambda^{\tau-1} \Mb_\lambda
\end{equation}

where $(\Mb_\lambda)_{ij}  = \pib \Tj \Pb_\lambda \Ti \one$ captures the contribution of the $\lambda$ eigenmode to the bigram probability. Plugging this into the definition of $\Cb_+$, for example reveals an interesting perspective on how attention interacts with the properties of the hidden process.

\begin{align}
    \Cb_+ &= \sum_{\tau=0}^{T-1} \sum_\lambda \lambda^\tau \alpha(\tau) \Mb_\lambda \\
    &= \sum_\lambda \left ( \sum_{\tau=0}^{T-1}  \alpha(\tau) \lambda^\tau  \right) \Mb_\lambda \\
    &= \sum_{\lambda} \alphatil(\lambda)\Mb_\lambda
\end{align}

Here $\alphatil(z) = \sum_{\tau}  \alpha(\tau) z^\tau $ is the \textit{generating function} of the mean lag distribution $\alpha(\tau)$. One way to think about this transform is as a discrete Laplace transform. Let $s = \log(1/z)$. Then $\alphatil(s) = \sum_{\tau}\alpha(\tau) e^{-s\tau} $ which we can identify as a Laplace transform of a distribution with discrete support. So we have discovered that for stationary hidden processes, the relevant statistics of the data are related to probing the attention profile at resonances associated with those of the underlying hidden dynamic. We can carry the same idea through to the other statistics as well:

\begin{align}
    \Cb &= \alpha(0)\Db + \sum_\lambda\left (\frac{\alphatil(\lambda) - \alpha(0)}{\lambda}\right) \Mb_\lambda \\
    &:= \alpha(0)\Db + \sum_\lambda \alphatil'(\lambda) \Mb_\lambda \\
    \Gb &= \gamma(0)\Db + \sum_\lambda\left (\frac{\gammatil(\lambda) - \gamma(0)}{\lambda}\right) (\Mb_\lambda + \Mb_\lambda^\top)\\
    &:= \gamma(0)\Db + \sum_\lambda\gammatil'(\lambda) (\Mb_\lambda + \Mb_\lambda^\top)
\end{align}

The more complicated functions of the transform are really just generating functions of a time shifted sequence 

\begin{align}
    \alphatil'(\lambda) &= \sum_{\tau = 0}^{T-2} \alpha(\tau + 1) z^{\tau}\\
    &= \frac{1}{z}\sum_{\tau = 0}^{T-2}\alpha(\tau + 1) z^{\tau + 1} \\
    &=  - \frac{\alpha(0)}{z} + \sum_{\tau = 0}^{T-1} \frac{1}{z}\alpha(\tau) z^{\tau} \\
    &= \frac{\alphatil(z) - \alpha(0)}{z}
\end{align}

This time shifted generating functions arise since they describe the co-occurrence of two tokens separated by $\tau$ steps. These statistics measure  correlation of the current token and a previous token, summed over a weighted history of previous tokens. The identity of the token at lag $\tau=0$ is known, so inference only needs to occur for $\tau\ge1$, hence the time shift. 

\subsection{Symmetry of the loss}
For fixed attention $\Ab$ Eq. \eqref{loss} defines a regression problem in the variable

\begin{equation}
    \Zb = 
    \begin{pmatrix}
        \Xb \\
        \Xb\Ab^\top
    \end{pmatrix}
\end{equation}

with correlation and target-cross-correlation identifiable as block matrices from the theory above:

\begin{equation}\label{blockXX}
\mathbb{E}[\Zb\Zb^\top] = 
    \begin{pmatrix}
        \Db & \Cb \\
        \Cb^\top & \Gb
    \end{pmatrix}  
\end{equation}
\begin{equation}\label{blockYX}
\mathbb{E}[\Yb\Zb^\top] = 
    \begin{pmatrix}
        \Bb^{(1)} & \Cb_+
    \end{pmatrix}  
\end{equation}
Notice that $\one^\top_{\vert\mathcal{V}\vert} \Xb = \one^\top_{\vert\mathcal{V}\vert} \Yb= \one^\top_T$ since each column of $\Xb$ (and $\Yb$) is a one-hot vector. Additionally, $\one^\top_T \Ab^\top = \one^\top_T$ from the row normalization of the attention matrix. The relationship can be succinctly captured in the following eigenvector equation. 

\begin{equation}\label{symmetry}
    \cb^\top \Zb = 0
\end{equation}
where $\cb^\top = \left(\one^\top_{\vert\mathcal{V}\vert}, -\one^\top_{\vert\mathcal{V}\vert}\right)$. By linearity of the expectation $\cb^T \mathbb{E}[\Zb\Zb^T] = 0$, so also Eq.\ref{symmetry} implies that certain combinations of the blocks in \eqref{blockXX} and \eqref{blockYX} will have a null singular value. For example, the Schur complements of \eqref{blockXX} have this property:
\begin{align}
    \Sb\one &= (\Gb - \Cb^\top \Db^{-1}\Cb)\one = 0 \label{snull}\\
    \Sb'\one &= (\Db - \Cb \Gb^{-1}\Cb^\top)\one = 0
\end{align}

These ideas can be used to show that many other combinations of the data correlations have $\one$ as in their left or right null space. A particularly useful example is 

\begin{equation}\label{rnull_left}
    \one^\top\Rb = \one^\top[\Cb_+ - \Bone\Db^{-1}\Cb] = 0  
\end{equation}

We can also show that $\one$ is a right eigenvector of $\Rb$ as well by using the probabilistic interpretations of the blocks:

\begin{align}
    \Rb \one &= 0 \label{rnull_right}\\
    &\implies [\Cb_+ - \Bone\Db^{-1}\Cb]\one = 0 \\
    &\implies \Cb_+\one = \Bone\one \\
    &\implies \Cb_+\one = \Db\one \\
    &\implies \sum_j \sum_\tau \alpha(\tau)P(x_{t} = i, x_{t-\tau-1} = j) = P(x_t = i) \\
    &\implies \sum_\tau \alpha(\tau)P(x_{t} = i) = P(x_t = i) \\
    &\implies P(x = i) = P(x = i)
\end{align}

In the second and third lines we have used the relationships $\Cb\one = \Db\one = \Bone\one $ which can be derived from \eqref{symmetry} and its corresponding generalization to the cross-correlation. In the final line we used the stationary of the hidden process to remove the time dependence from the single token probabilities. From the perspective of the parameters, \eqref{symmetry} implies the existence of a $\vocab$-dimensional manifold in parameter space that yield equivalent loss. In particular the following transformations leave the loss \eqref{loss} unchanged for any $\ub \in \mathbb{R}^{\vocab}$:

\begin{align}\label{param_degen}
    \Wb &\to \Wb + \ub\one_{\vocab}^\top \\
    \Vb &\to \Vb - \ub\one_\vocab^\top
\end{align}


\subsection{Optimal solution for frozen attention and its probabilistic interpretation}
In terms of the data statistics we have calculated, the gradient of the loss \eqref{long_gW}-\eqref{long_gV} become 

\begin{align}
     \nabla_{\Wb}\mathcal{L} &= - \Bb^{(1)}+\Wb \Db + \Vb \Cb^\top \label{gW}\\ 
     \nabla_{\Vb}\mathcal{L} &= - \Cb_{+} + \Wb\Cb + \Vb \Gb \label{gV}
\end{align}

By setting these equations equal to zero, we can solve for the optimal direct and context dependent matrices. Setting \eqref{gW} equal to zero implies:

\begin{align}
    \Wb_* &= \Bone \Db^{-1} - \Vb_*\Cb^\top \Db^{-1} \\  
\end{align}
Plugging this in to \eqref{gV} and setting equal to zero gives

\begin{align}
    \Vb_*[\Gb - \Cb^\top \Db^{-1}\Cb] &= [\Cb_+ - \Bone \Db^{-1}\Cb] \\
    \Vb_* \Sb &= \Rb \label{vfeasibility}
\end{align}

From \eqref{snull}, \eqref{vfeasibility} does not have a unique solution. However, \eqref{vfeasibility} implies that $\Vb_*\Sb\one = \Rb\one=0$ which is always satisfied for a stationary process as shown in \eqref{rnull_right}. We can parameterize all solutions using the Moore-Penrose pseudoinverse of $\Sb$, which gives 

\begin{align}
    \Vb_{*} &= \Rb\Sb^+ + \ub\one^\top \label{vstar}\\
    \Wb_{*} &= \Bb^{(1)}\Db^{-1} - \Rb \Sb^+ \Cb^\top \Db^{-1} - \ub\one^\top\label{wstar}
\end{align}

for any $\ub$. Immediately we can see that the direct path involves the bigram predictor $\Bb^{(1)}\Db^{-1}$ whose elements are $P(x_{t+1} = i | x_t = j)$, as well as a contribution from the attended sequence, $\Vb_* \Cb^\top \Db^{-1}$. We will see in the following that this contribution to the direct path removes information about previous context that could be learned from the current token alone. We can begin by understanding how the value circuit maps attended context to next token information. Suppose we regress the next token from the current context $\Xb$, forming a bigram predictor $\mathbb{E}[\Yb\Xb^\top]\mathbb{E}[\Xb\Xb^\top]^{-1} = \Bb^{(1)}\Db^{-1}$. The residual information in $\Yb$ after using the current token is $\Rb_{\Yb|\Xb} = \Yb - \Bb^{(1)}\Db^{-1}\Xb$. The information that is present in the attended context beyond what is present in the current context can be found by this same regressing out procedure. The best approximation to $\Xb \Ab^\top$ from $\Xb$ is $(\mathbb{E}[\Xb\Ab^\top\Xb^\top]\mathbb{E}[\Xb\Xb^\top]^{-1})\Xb = \Cb^\top \Db^{-1}\Xb$. Removing this contribution from the attended context we can form the residual vector $\Rb_{\Xb \Ab^\top | \Xb} = \Xb\Ab^\top - \Cb^\top\Db^{-1}\Xb$. We can now try to construct the rest of the next token information from the attended context residual by regressing $\Rb_{\Xb \Ab^\top | \Xb}$ onto $\Rb_{\Yb|\Xb}$. This would yield a regression coefficient 
\begin{align}
    &\mathbb{E}[\Rb_{\Yb|\Xb}\Rb_{\Xb \Ab^\top | \Xb}^\top]\mathbb{E}[(\Rb_{\Xb \Ab^\top | \Xb})(\Rb_{\Xb \Ab^\top | \Xb})^\top]^{+}\\
    &= \mathbb{E}[(\Yb - \Bb^{(1)}\Db^{-1}\Xb)(\Xb\Ab^\top - \Cb^\top\Db^{-1}\Xb)^\top)]\mathbb{E}[(\Xb\Ab^\top - \Cb^\top\Db^{-1}\Xb)(\Xb\Ab^\top - \Cb^\top\Db^{-1}\Xb)^\top]^{+} \\
    &= \underbrace{[\Cb_+ - \Bb^{(1)}\Db^{-1}\Cb]}_{\substack{\textrm{correlation between $\Yb$} \\ \textrm{and $\Xb\Ab^\top$ after regressing out $\Xb$}}}\underbrace{[\Gb - \Cb^\top \Db^{-1}\Cb]^{+}}_{\substack{\textrm{variance in $\Xb\Ab^\top$} \\ \textrm{after regressing out $\Xb$}}}
\end{align}

which is exactly $\Vb_*$. So $\Vb_*$ maps information in the attended context, beyond what is present in the current token, to next token information. Here, we have implicitly assumed that $\ub = 0$ for simplicity, but the story is the same for nonzero $\ub$. This idea goes by the name \textit{partial regression} in the statistics literature and is a general way of interpreting regression coefficients when you have regressors that are not independent of one another. 
\newline
\newline
\newline
With this understanding of the matrix $\Vb_*$ we can try to understand the computation that the optimized network performs on a given sequence. Let $\bar{\xb}_t = (\Xb \Ab^\top)_{:,t} = \sum_{s\le t} A_{ts}\xb_s = \sum_{\tau=0}^{t-1} A_{t, t-\tau}\xb_{t-\tau}$ be the attended context at position $t$. At context position $t$, the optimal predictor is 

\begin{align}
    f(\Xb)_t = \Bb^{(1)}\Db^{-1}\xb_t + \Vb_* \left ( \bar{\xb}_t - \Cb^\top\Db^{-1} \xb_t \right ) 
\end{align} 

We can identify the first term as the bigram prediction $P(\xb_{t+1} \mid \xb_t)$ and the second as an update to this bigram distribution given context. To this end we can write the full attention matrix as the mean lag distributions plus context (row) dependent corrections:

\begin{align}
    A_{t,t-\tau} = \alpha(\tau) + \delta(t, \tau)
\end{align}

Averaging both sides of this equation over the rows $\frac{1}{T}\sum_{t=\tau+1}^T$ yields:
\begin{align}
    \frac{1}{T}\sum_{t=\tau+1}^T A_{t,t-\tau} &= \frac{1}{T}\sum_{t=\tau+1}^T \alpha(\tau) + \frac{1}{T}\sum_{t=\tau+1}^T\delta(t, \tau) \\
    \alpha(\tau) &= \frac{T-\tau}{T}\alpha(\tau) + \frac{1}{T}\sum_{t=\tau+1}^T\delta(t, \tau)
\end{align}

which shows that 
\begin{equation}
    \frac{1}{T}\sum_{t=\tau+1}^T  \delta(t, \tau) = \frac{\tau}{T} \alpha(\tau) \to 0 \;\; \text{for $\tau \ll T$}
\end{equation}
implying that the average of the row dependent fluctuations vanishes in the large context, finite lag limit. Using this, we can split the attended context into two terms.

\begin{align}
    \bar{\xb}_t = \underbrace{\sum_{\tau=0}^{t-1}\alpha(\tau)\xb_{t-\tau}}_{\bar{\xb}_t^{(\alpha)}} +  \underbrace{\sum_{\tau=0}^{t-1}\delta(t,\tau)\xb_{t-\tau}}_{\bar{\xb}_t^{(\delta)}}
\end{align}

The term $\xb_t^{(\alpha)}$ captures the mean attended context while $\xb_t^{(\delta)}$ captures the attended context that is specific to the particular context position $t$. Next we can use \eqref{XAX} and \eqref{btau} to find a probabilistic description for the $\Cb^T\Db^{-1}$ term. 

\begin{align}
 \Cb^\top\Db^{-1} \xb_t &= \sum_{\tau = 0}^{T-1} \alpha(\tau) \frac{P(\xb_{t-\tau}, \xb_t)}{P({\xb_{t}})} \\
 &= \sum_{\tau = 0}^{T-1} \alpha(\tau) P(\xb_{t-\tau} | \xb_{t}) \\
 &= \mathbb{E}[\bar{\xb}_t^{(\alpha)} \mid \xb_t] -  \sum_{\tau = t}^{T-1} \alpha(\tau) P(\xb_{t-\tau} | \xb_{t})
\end{align}
The correction in the final line is written schematically as a probability, although in reality this is not well defined since $x_t$ is not defined for negative $t$. This is a manifestation of the fact that the statistics $\Cb$ and $\Db$ are calculated for the entire sequence of length $T$ while we are looking at the behavior of the predictor for some intermediate time $t$. This truncation effect becomes small deep in the sequence when $t$ is large. The computation that the optimal network performs at a context position $t$ can be interpreted probabilistically as

\begin{equation}
    f(\Xb)_t = \underbrace{\Bb^{(1)}\Db^{-1}\xb_t}_{\text{bigram prediction}} + \Vb_* \underbrace{\left ( \bar{\xb}_t^{(\alpha)} -  \mathbb{E}[\bar{\xb}_t^{(\alpha)} \mid \xb_t] \right )}_{\substack{\text{average attended signal} \\ \text{remaining in observed} \\\text{context given current position}}} + \underbrace{  \Vb_*\bar{\xb}_t^{(\delta)}}_{\text{row dependent fluctuations}} + \underbrace{ \Vb_*\sum_{\tau = t}^{T-1} \alpha(\tau) P(\xb_{t-\tau} | \xb_{t})}_{\text{truncation effects}}
\end{equation}



\section{Optimal solution in parameter space}
So far we have described the optimal solution in function space by defining the effective parameter matrices $\Wb_* = \Wb_U\Wb_E, \Vb_* = \Wb_U \Wb_{OV}\Wb_E$, which reduced the optimization to a quadratic objective. In this section we will construct solutions for the parameters $\Wb_E, \Wb_U, \Wb_{OV}$ which combine to form the optimal effective parameters. This solution also gives an interpretation of the network computation where beliefs over latent states are updated in a subspace of the residual stream. Assume the gauge vector $\ub = 0$. It is useful to divide $\Vb_*$ and $\Wb_*$ into their stationary and nonstationary components. We begin by showing a very useful property of the spectral bigram matrices $\Mb_\lambda$:

\begin{align}
    \sum_j(\Mb_\lambda)_{ij} &= \sum_j \pib^\top \Tb^{(j)}\Pb_\lambda\Tb^{(i)}\one\\
    &= \pib^\top \sum_j \Tb^{(j)}\Pb_\lambda\Tb^{(i)}\one\\
    &=  \pib^\top \Tb\Pb_\lambda\Tb^{(i)}\one \\
    &= (\pib^\top \Tb^{(i)}\one) \delta_{\lambda,1} \\
    &= (p_i) \delta_{\lambda,1}
\end{align}

where $p_i$ is the observation probability for the single token indexed by $i$. A similar calculation shows that summing over the first index of $\Mb_\lambda$ yields a similar result. In summary,

\begin{align}\label{mone}
    \Mb_\lambda \one &= \pb \delta_{\lambda,1} \\
    \one^\top \Mb_\lambda &= \pb^\top \delta_{\lambda,1}
\end{align}

In this notation, $\Mb_1 = \pb \pb^\top$.
The matrix $\Vb_* = \Rb \Sb^{+}$ %where we have defined $\Rb = \Cb_+ - \Bb^{(1)}\Db^{-1}\Cb$ and $\Sb = \Gb - \Cb^\top \Db^{-1}\Cb$. 

\begin{align}
    \Rb &= \Cb_+ - \Bb^{(1)}\Db^{-1}\Cb \\
    &= \left(\sum_\lambda \alphatil(\lambda) \Mb_\lambda\right) - \left(\sum_\mu \Mb_\mu \left(\alpha(0)\Ib + \sum_\lambda \alphatil'(\lambda)\Db^{-1} \Mb_\lambda\right) \right) \\
    &= \left(\sum_\lambda \lambda\alphatil'(\lambda)\Mb_\lambda\right) - \sum_{\lambda\mu}\alphatil'(\lambda)\Mb_\mu\Db^{-1}\Mb_\lambda\ \\

    &= \sum_{\lambda \neq 1}\alphatil'(\lambda) \underbrace{\left [ \lambda \Ib - \sum_{\mu\neq 1}\Mb_\mu \Db^{-1}\right]\Mb_\lambda}_{\hat{\Mb}_\lambda} \\
    &:=  \sum_{\lambda \neq 1}\alphatil'(\lambda) \hat{\Mb}_\lambda \label{r}
\end{align}

Defining $\Fb = \sum_{\lambda\neq 1} \alphatil'(\lambda) \hat{\Mb}'_\lambda \Sb^+ \in \mathbb{R}^{|\mathcal{S}|\times |\mathcal{V}|}$ we can understand the existence of solutions to \eqref{selfcons} in terms of the dimensionality of the matrices. Assume $\We$ and $\Fb$ are full rank, meaning $\textrm{rank}(\We) = \textrm{rank}(\Fb) = \min(|\mathcal{S}|,|\mathcal{V}|)$

\begin{itemize}
    \item $\mathbf{|\mathcal{S}| > |\mathcal{V}|}$: a solution always exists but it is not unique. The least squares solution is $\Wb_{OV} = \Fb \We^+$ and any other solution can be formed by adding a matrix $\Nb$ whose rows are orthogonal to the columns of $\We$ so that $\Nb \We = 0$. 
    \item $\mathbf{|\mathcal{S}| = |\mathcal{V}|}$: if a solution exists it is unique
    \item $\mathbf{|\mathcal{S}| < |\mathcal{V}|}$: generically no exact solution. A unique least squares solution exists, as always, but it does not satisfy the constraint.
\end{itemize}

    \Wb_{OV} &= \Fb \We^+ + \Nb \label{wov_summ}
\end{align}

If we now let $d \ge |\mathcal{S}|$, we can form a solution in the following way. Let $\Psib$ be a linear map $\Psib : \mathbb{R}^{|\mathcal{S}|}\to \mathbb{R}^d$ with $\mathrm{rank}(\Psib) = |\mathcal{S}|$. Then $\Psib$ has a left inverse $\Psib'$ such that $\Psib' \Psib = \Ib_{|\mathcal{S}|}$. Then the following set of transformations to the above factorization \eqref{wu_summ}-\eqref{wov_summ} form a family of $d-$dimensional optimal solutions.

\begin{align}
    \Wb_U &\to \Wb_U \Psib' \\
    \Wb_E &\to \Psib \We \\
    \Wb_{OV} &\to  \Psib \Wb_{OV} \Psib'
\end{align}

Together these force $\one_\state\Wb_E = \one$. This means that the embedding maps every token to a vector with sum one. In other words, a signed distribution, which is further evidence of the simplex interpretation of the parameter mappings. 

\section{Optimal attention profile and the spectrum of the latent dynamic}
So far we have described the optimal solution for direct and indirect path parameters, $\Wb_*$ and $\Vb_*$ in terms of a fixed attention profile. We now turn to deriving the optimal attention pattern. Plugging in $\Vb_*(\Ab)$ and $\Wb_*(\Ab)$ into the loss \eqref{loss}, we get 

\begin{align}\label{factoredloss}
    \mathcal{L}(\Ab) &= \underbrace{\frac{1}{2}\tr(\Db)}_{\text{unigram}} - \underbrace{\frac{1}{2}\tr(\Bone \Db^{-1}(\Bone)^\top)}_{\text{bigram}} - \underbrace{\frac{1}{2}\tr(\Rb \Sb^+\Rb^\top)}_{\text{skip-bigram}}
\end{align}

\eqref{factoredloss} has several interesting consequences. First, notice that we can think of the loss as a series of refinements to the error of guessing the next token according to the marginal unigram statistics: the first refinement is to use the preceding token (bigram) and the second is to use linear combinations of single past tokens from positions earlier in the context (skip-bigram). Second, note that the only term that depends on attention is the skip-bigram, which makes sense, since attention is the only part of the architecture that can incorporate this kind of information. Finding the optimal attention profile amounts to \textit{maximizing} the function 

\begin{equation}\label{lattn}
    \mathcal{L}_{\text{attn}} = \frac{1}{2}\tr(\Rb\Sb^+\Rb^\top)
\end{equation}

Furthermore, this function only depends on $\left\{\{\alphatil'(\lambda), \gammatil'(\lambda)\}_{\lambda\neq1}, \alpha(0), \gamma(0)\right\}$. So the optimization over $T^2$ variables has become one over two functions of the matrix $A$ evaluated at the nonstationary eigenvalues of the latent process. Using the process statistics in \ref{sec:stats} we can derive an expression for the matrix $\Sb$ which makes the dependence on the summary statistics explicit. The expression for $\Rb$ in \eqref{r} is repeated below for convenience

\begin{align}\label{s}
      \Sb &= \left(\gamma(0) - \alpha(0)^2\right)(\Db - \pb\pb^\top)\\
      &+ \sum_{\lambda \neq 1}\left( \gammatil'(\lambda) - \alpha(0)\alphatil'(\lambda)\right ) \left( \Mb_\lambda + \Mb_\lambda^\top\right) \\
      &- \sum_{\mu\neq 1, \lambda\neq 1} \alphatil'(\lambda)\alphatil'(\mu)\Mb_\lambda^\top \Db^{-1}\Mb_\mu
\end{align}

\begin{align}
     \Rb &= \sum_{\lambda \neq 1}\alphatil'(\lambda) \hat{\Mb}_\lambda \\
     \hat{\Mb_\lambda} &= \left(\lambda\Ib - \sum_{\mu\neq1}\Mb_\mu\Db^{-1}\right)\Mb_\lambda
\end{align}

\textbf{I have not been able to find an analytic solution for the optimal parameters. From this point on, I will just catalog some observations and potential paths forward. I have attempted all of these paths and they are all complicated but I don't think any are truly dead}

\subsection{Path I: KKT conditions}
One path forward is to try to write down the conditions for critical points of $\mathcal{L}_{\text{attn}}$ y using the KKT conditions. The hurdle here is that enumerating all of the necessary constraints on $\left\{\{\alphatil(\lambda), \gammatil(\lambda)\}_{\lambda\neq1}, \alpha(0), \gamma(0)\right\}$. It may seem like this is an optimization over $2\state$ numbers, but these numbers must be realizable. The fact that all of these quantities are derived from a a nonnegative, lower-triangular, row-stochastic matrix induces constraints among them. Some constraints, like the bounds for the individual variables are easily derived from their definitions:

\begin{itemize}
    \item $0 \leq \alpha(0) \leq 1$ 
    \item $0 \leq \gamma(0) \leq 1$ which follows from recognizing $\gamma(0) = \frac{1}{T}\normsq{\Ab}{F} \leq \frac{1}{T}\sum_{ij} A_{ij} = 1$. 
    \item $\vert \alphatil(\lambda)\vert \le 1$ which follows from the eigenvalues being contained in the unit disc in the complex plain
    \item $\frac{\gamma(0)}{2} \leq \gammatil(\lambda) \leq \frac{1 + \gamma(0)}{2}$
\end{itemize}

The final constraint is actually a realization of a more exotic constraint which can be derived with a bit of complex analysis. The basic idea is to bound $|\alphatil(\lambda)|^2$ by an expression involving $\gammatil(\lambda), \gamma(0)$ when $|\lambda| = 1$, leading to something like $H(\lambda) \ge 0$ on the boundary of the disc. Then you can show that $H(\lambda)$ is a superharmonic function of $\lambda$
 which gaurantees, by the minimum principle, that it achieves its minimum on the boundary of the disc which proves the inequality holds for any $\lambda$. The result is 

 \begin{equation}
     2 \Re[\gammatil(\lambda)] + \gamma(0) - |\alphatil(\lambda)|^2 \geq 0
 \end{equation}

 This method is direct and sort of mechanical, but the main issue I have is that the I can't guarantee that I have found all of the constraints. And the first order conditions are hard to interpret.

 \subsection{Path II: stationary approximation}
Another option is to consider a sort of \textit{row stationary} approximation to the attention matrix

\begin{equation}\label{astat}
    \Ab = \begin{pmatrix}
        a_0 & 0 & 0 & 0 & \dots  &0 &0\\
        a_1 &a_0 & 0 & 0 & \dots  &0 &0\\
        a_2 &a_1 & a_0 & 0 & \dots  &0 &0\\
        &&&\vdots & \\
        a_s & a_{s-1} & \dots & a_1 & a_0  & 0 & \dots \\
        \vdots & \vdots &\vdots 
    \end{pmatrix}
\end{equation}

 Because of the row normalization constraint on $\Ab$ this only really makes sense in the $T \to \infty$ limit. So this means that the rows of the \textit{infinite} attention matrix are shifted copies of the same sequence $\{a_\tau\}_{\tau=0}^\infty$. The mean lag distribution is easy to calculate:

 \begin{align}
     \alpha(\tau)  &= \lim_{T\to \infty}\frac{1}{T}\sum_{\tau+1}^T A_{t, t-\tau} \\ 
     &= \lim_{T\to \infty}\frac{T - \tau}{T} a_\tau \\
     &= a_\tau
 \end{align}

The mean autocorrelation turns out to just be the autocorrelation of the sequence $a_\tau$ which is the primary benefit of this approximation 

\begin{align}
    \gamma(\tau) &= \lim_{T\to \infty}\sum_{t=\tau+1}^T\sum_{s=t}^T A_{st}A_{s,t-\tau} \\
    &= \lim_{T \to \infty}\sum_{t=0}^{T-\tau-1}\frac{T-\tau-t}{T}a_ta_t+\tau \\
    &= \sum_{t=0}^\infty a_t a_{t+\tau} 
\end{align}

Therefore the attention optimization problem becomes expressible only in terms of $\alphatil'(\lambda)$ and $\alpha(0)$. This path is promising-- it can be combined with the KKT approach. It also becomes quite complicated. 

\subsection{Path III: a simple two state system}
Another path forward is to try to solve the optimization for a particularly simple class of HMMs in the hopes that things become easier and we can gain some intuition for the full problem. To this end I have focused on a two-hidden-state, two-token process. 

The total transition matrix $T$, and symbol labeled transition matrices $T^{(i)}$ can be parameterized without loss of generality as 

$$
T = \begin{pmatrix}
1-s_1 & s_1\\
s_2 & 1-s_2
\end{pmatrix}
$$
$$
T^{(1)} = \begin{pmatrix}
\theta_1(1-s_1) & \theta_1s_1 \\
\theta_2 s_2 & \theta_2(1-s_2)
\end{pmatrix}
$$
$$
T^{(2)} = \begin{pmatrix}
(1-\theta_1)(1-s_1) & (1-\theta_1)s_1 \\
(1-\theta_2) s_2 & (1-\theta_2)(1-s_2)
\end{pmatrix}
$$
From the transition matrix it is straightforward to show that the spectrum of T is 
$$
\text{spec}(T) = \{1, 1- (s_1+s_2) \}
$$
From this point on we will call the nonstationary eigenvalue $\lambda = 1 - (s_1 + s_2)$. The stationary distribution is

$$
\pi^T = \frac{1}{s_1 + s_2}\begin{pmatrix}
s_2 & s_1
\end{pmatrix}
$$

with right eigenvector $1$, the two dimensional vector of ones. The nonstationary right and left eigenvectors are 
$$
r_\lambda = \frac{1}{s_1+s_2}\begin{pmatrix}
	s_1 \\ -s_2 
\end{pmatrix} \;\;\;\;\;\;\;\;\;\;
v^T = 
\begin{pmatrix}
	1 & -1 
\end{pmatrix}
$$
The stationary symbol probabilities are:

\begin{align}
	p_1 &= \pi^T T^{(1)}1 = \frac{\theta_1s_2 + \theta_2s_1}{s_1+s_2}\\
	p_2 &= \pi^T T^{(2)}1 = \frac{(1-\theta_1)s_2 + (1-\theta_2)s_1}{s_1+s_2}
\end{align}
Note that this gives $p_1 + p_2 = 1$ as expected. Define the vector 

$$
p = 
\begin{pmatrix}
	p_1 \\p_2
\end{pmatrix}
$$
and the matrix 
$$
D = 
\begin{pmatrix}
	p_1 & 0 \\
	0 &p_2
\end{pmatrix}
$$

We can also find an expression for $\Mb_\lambda$

\begin{align}
(M_\lambda)_{ij} &= \pi^T T^{(j)} r_\lambda v^T T^{(i)}1 \\
\implies M_\lambda &= m_\lambda vv^T
\end{align}

where 
$$
m_\lambda = \frac{\lambda s_1 s_2}{(s_1 + s_2)^2}(\theta_1 - \theta_2)^2
$$
Now all of the necessary ingredients are in place to find an expression for $\mathcal{L}_{\text{attn}}$. Using \eqref{s} \eqref{lattn} we can find that 

\begin{equation}
    \mathcal{L}_{\text{attn}} = \frac{\alphatil'_\lambda^2(m_\lambda^2)(\lambda - m_\lambda/p_1p_2)^2}{p_1p_2(\gamma_0 - \alpha_0^2) + 2m_\lambda(\gammatil'_\lambda - \alpha_0\alphatil'_\lambda) - m_\lambda^2 \alphatil'_\lambda^2/p_1p_2}
\end{equation}

This equation is also quite complicated to optimize.
