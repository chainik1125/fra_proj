# Simplexity — Minimal Setup

A minimal setup for training small predictive models on sequences generated by Hidden Markov Models using [simplexity](https://github.com/Astera-org/simplexity), then probing their internal representations.

This branch is stripped down to a single training loop and one analysis notebook:
- `training/run_minimal.py` — a no-Hydra, no-MLflow training loop (`Config`, `build_model`, `train`)
- `training/matrices.py` — custom HMM transition matrices (direct-sum, Kronecker, AFP builders)
- `analysis/act_avg_claude.ipynb` — direct-sum N-coin experiment + activation-averaging analysis

## Setup

```bash
uv sync
```

## Usage

### Minimal training from the CLI

```bash
# Defaults (mess3 process, 2-layer transformer)
uv run python training/run_minimal.py

# Override via CLI flags
uv run python training/run_minimal.py --num_steps 100 --n_layers 4

# Load a YAML config
uv run python training/run_minimal.py --config path/to/config.yaml
```

`run_minimal.py` exposes `Config`, `build_model(cfg, vocab_size)`, and
`train(model, hmm, cfg)` for use directly from notebooks — see
`act_avg_claude.ipynb` for the canonical example.

### Analysis notebook

`analysis/act_avg_claude.ipynb` trains a transformer on a direct sum of N biased-coin
HMMs, compares per-position loss against the Bayes-optimal predictor, then applies
activation averaging (grouping activations by dominant coin and running PCA) to
visualize how coin identity is represented across layers.

## Adding a custom HMM generator

See `training/matrices.py`. Steps:
1. Define a function that returns transition matrices as a JAX array.
2. Register it with `HMM_MATRIX_FUNCTIONS["your_name"] = your_function`.
3. Build it via `build_hidden_markov_model("your_name", params)`, or use one of the
   higher-level builders (`build_direct_sum_hmm`, `build_kronecker_hmm`).
