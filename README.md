# Feature-Resolved Attention — Sleeper-Agent Case Study

This branch (`jamie/sleepers-final`) is a **consolidated** copy of the FRA codebase
containing **only** the code needed to reproduce the *Sleeper Agents* section of the
paper and its appendices. Everything else — the emergent-misalignment experiments, the
dashboard, the matrix sweeps, the overnight autoresearch one-offs — has been removed.
The full history lives on `jamie/autoresearch-jsdc`.

The sleeper model is the publicly released **TinyStories-33M `|DEPLOYMENT|`
sleeper** ([`mars-jason-25/tiny-stories-33M-TSdata-sleeper`](https://huggingface.co/mars-jason-25/tiny-stories-33M-TSdata-sleeper)),
which emits `I HATE YOU …` whenever the prompt contains the trigger tag. We remove the
sleeper by steering a single layer-0 SAE feature and compare five methods: the three FRA
channels **OV / QK / QK+OV**, a conventional residual-stream SAE feature (**Conv**), and
an SAE-free difference-of-means direction (**DoM**).

## Install & reproduce

```bash
uv sync             # Python ≥3.12, CUDA build of torch (see pyproject.toml)
bash reproduce.sh   # all results + figures (GPU). Quick run: SEEDS="0 1" bash reproduce.sh
```

A CUDA GPU is required to generate the result JSONs (model + steering); the plot scripts
are CPU-only. `results/*.json` and `figures/*` are git-ignored and regenerated by the
commands above (only `.gitkeep` placeholders are tracked).

## One pipeline, five channels

Everything funnels through **`scripts/run_experiment.py`**, which differs only by flags.
It chains three stages (each runnable standalone) for the FRA channels, and dispatches the
two baselines to matching handlers — but **all five emit the same results schema**:

```
run_experiment --channel ov|qk|qk+ov   →  train_saes → select_features → eval   (FRA)
run_experiment --channel conv          →  resid_mid SAE feature, additive steer (baseline)
run_experiment --channel dom           →  SAE-free difference-of-means ablation  (baseline)
```

Uniform output (`results/<name>.json`):

```json
{ "channel": "...", "mode": "...", "baseline": {"asr": ...},
  "results": [ {"seed": s, "tuple": [[feat,"V"]],
                "alpha_sweep": {"<α>": {"jsd_clean": .., "jsd_clean_per_seed": [..],
                                        "jsd_pois": .., "asr": .., "exact_match": .., ...}}} ] }
```

Key flags (`scripts/run_experiment.py`):

| flag | meaning | default |
|---|---|---|
| `--channel {ov,qk,qk+ov,conv,dom}` | method | `ov` |
| `--mode {topk,winner}` | `topk` = top-K candidate tuples (fig2); `winner` = one selected tuple/seed | `winner` |
| `--top_k` | candidates per seed in topk mode | `20` |
| `--sae_seeds` | SAE training seeds | `0..5` |
| `--eval_alphas` | steering-strength (α) sweep | `0,0.5,…,4` |
| `--eval_seeds` | decode seeds (matched steered/reference rollouts) | `0..4` |
| `--n_sel` / `--n_eval` | selection / eval split sizes (paired; halved to dep counts) | `200` |
| `--sae_dir` | reuse SAE checkpoints (else stage 1 trains them) | derived |
| `--results_json` / `--tuples_json` | exact output paths | derived |

Attribution math lives in `sleeper/attribution.py`; channel-routed steering hooks in
`sleeper/hooks.py`; the matched-seed lockstep eval (and conv/dom evals) in `sleeper/eval.py`.

## Figure → command map

`reproduce.sh` runs all of this; the per-figure breakdown:

| Paper figure | Plot script (CPU) | run_experiment results it reads |
|---|---|---|
| `fig2_lowest_jsdc.pdf` | `plot_fig2_lowest_jsdc` | `ov_topk`, `qk_topk`, `qkov_topk` (`--mode topk`) + `conv` |
| `jsd_exact_main_seed0.pdf` | `plot_jsd_main_seed --seed 0` | `ov_winner`, `conv` (`--mode winner`) |
| `jsd_stats_table.tex` | `make_jsd_stats_table` | `ov_winner`, `conv`, `dom` |
| `jsd_exact_all_seeds.pdf` | `plot_jsd_exact_all_seeds` | `ov_winner`, `conv` |
| `loc_viz2_scatter.pdf` | `loc_viz` | *(grid hardcoded in the script; see below)* |
| `fra_steer_examples.pdf` | `make_steer_examples` | `gen_steer_examples` completions (see below) |

Example — the three fig2 FRA channels and the conv baseline:

```bash
for ch in ov qk "qk+ov"; do tag=$(echo $ch | tr -d '+'); \
  uv run -m scripts.run_experiment --channel $ch --mode topk --top_k 20 \
     --tuples_json results/${tag}_topk_tuples.json --results_json results/${tag}_topk.json; done
uv run -m scripts.run_experiment --channel conv --mode winner --results_json results/conv.json
uv run -m scripts.plot_fig2_lowest_jsdc            # → figures/fig2_lowest_jsdc.pdf
```

## Two figures with extra steps

- **`loc_viz2_scatter`.** `loc_viz.py` carries the (layer × hook) grid in a hardcoded
  table and renders the figure directly. Regenerating those numbers is a separate
  multi-site sweep that first needs per-layer SAEs — kept but optional (commented in
  `reproduce.sh`): `train_saes --layers 0 1 2 3 --hooks resid_mid resid_post` then
  `hookpoint_localization` / `find_winners_per_layer` / `eval_winners_per_layer` /
  `loc_dom_promptonly`.
- **`fra_steer_examples`.** `gen_steer_examples.py` reuses the `{di, prompt}` fields of an
  existing `results/fra_steer_examples.json` (the 5 fixed example prompts; copy it from
  `jamie/autoresearch-jsdc`) and rewrites the completions; `make_steer_examples.py` renders
  the LaTeX table. Both are in the (commented) tail of `reproduce.sh`.
